## Convolutional Neural Networks (CNN)  Tutorial & Implementation
This is the repository that has the entire tutorial, code, and supporting files used in the assignment project on Convolutional Neural Networks (CNNs).
It includes:
* A PDF that explains CNN concepts
* A Notebook with complete runnable code
* References and external resources
* License

## Project Description
This project features a beginner-friendly tutorial on Convolutional Neural Networks, including:
* The mechanism of the convolution, pooling, and fully connected layers.
* The way CNNs acquire hierarchical features.
* Mutual network with a complete code on the MNIST data.
* The practical work with filters and kernel sizes.
* Visualizing accuracy of training and learned kernels.
## Installation
1. Open **cnntutorial.ipynb** in Google Colab.
2. Make sure TensorFlow and matplotlib are installed (Colab has these pre-installed).
3. Run all cells to:
   * Load MNIST dataset  
   * Train the CNN model  
   * Generate plots
  
## Dataset
**MNIST dataset**: 70,000 grayscale images of handwritten digits (0–9), 28×28 pixels. Loaded directly using TensorFlow/Keras.
